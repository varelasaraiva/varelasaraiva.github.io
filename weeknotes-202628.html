I spent some productive late evenings digital gardening. Was I procrastinating, trying to put off an important task that needed to be done ASAP? No, not at all. As a result, the new features that I’ve been planning for some time have finally landed. Here’s a list of changes:

  • Added autolinking the first occurrence of words or n-grams in markdown content to existing wiki node slugs, titles or aliases. It supports a blocklist file to specify nodes that are not meant to be autolinked.
  • Added autolinking of words or n-grams to an external URL, as mapped in a JSON file.
  • The weeknotes archive is now dynamically generated.
  • Added better navigation to individual weeknotes.
  • Applied typographical embellishments like auto replacing dashes with en- or em-dashes, straight quotes with curly quotes, and shortcodes with emojis.

If something breaks, please let me know.
